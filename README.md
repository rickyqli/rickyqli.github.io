# 李强 - 个人学术网站

## 🌐 在线访问
访问地址：[https://rickyqli.github.io](https://rickyqli.github.io)

## 📋 主要功能

- **响应式设计**：在桌面端、平板和移动设备上完美呈现
- **研究展示**：展示研究
- **学术成果**：学术论文和会议演讲
- **摄影画廊**：个人、风景和纪实摄影作品，带灯箱浏览器
- **侧边导航**：跟随滚动的固定导航栏
- **交互界面**：平滑滚动、悬停效果和动画

## 🛠️ 使用技术

- HTML5
- CSS3（包含 CSS 变量和 Flexbox/Grid）
- 原生 JavaScript
- Google Fonts（Crimson Text、Lato）
